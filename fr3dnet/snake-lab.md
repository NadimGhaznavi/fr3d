# Snake Lab Service

The **Snake Lab** provides a service for running **reinforcement-learning simulations**.

Each simulation has an AI agent playing the game of Snake. The goal is to eat as much food as possible, with one point awarded for each item of food eaten. A game ends when the snake collides with itself or with the edge of the board.

Snake Lab accepts **simulation configurations** and executes them. Configuration data, runtime data, and simulation results are stored and made available to Snake Lab users.
