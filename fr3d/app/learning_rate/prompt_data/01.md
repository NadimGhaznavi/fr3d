# Choose a learning rate

Snake Lab trains a reinforcement-learning agent to play Snake. Choose a learning
rate that will help achieve the highest game score. High score is the objective.
Only the learning rate changes; all other experiment settings remain fixed.

Use `view_experiment_report` to inspect the latest completed experiment, or pass
an `experiment_id` to inspect a particular completed experiment. Report data is
JSON. Runtime is in seconds; null means unavailable, not zero.

Submit your choice using `submit_learning_rate`. Supply only `learning_rate`,
a finite number greater than zero and at most one. A prose answer does not submit
an LR. You may inspect reports before submitting.
