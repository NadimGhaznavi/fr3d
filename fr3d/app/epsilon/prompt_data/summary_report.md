# Choose a New Epsilon Decay

Snake Lab trains a reinforcement-learning agent to play Snake. Choose an epsilon decay that will help achieve the highest game score. High score is the objective. Only epsilon decay changes; all other experiment settings remain fixed.

The summary report below contains completed experiment IDs, epsilon decay values, and high scores. Choose an epsilon decay that has not already been used. Historical results may come from different settings or versions.

Submit your new choice using `submit_epsilon_decay`. Supply only `epsilon_decay`, a finite number greater than zero and at most one. A prose answer does not submit an epsilon decay. Report data is JSON; null means unavailable, not zero.
